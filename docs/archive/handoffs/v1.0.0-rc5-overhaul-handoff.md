## 3. Concrete Specifications for the Agent Architecture Overhaul

### Directive 1: Eliminate the "Mute Subagent Trap" & Fix Tooling Paradox
- **Target File**: `harness/subagents.py`
- **Root Cause Identified in Deep Dive**:
  Subagents spawned by Antigravity lack `send_message` in their tool groups and frontmatter capabilities. When their task concludes or encounters blockers, they cannot notify their parent or coordinator; they stall silently in `idle` or loop until killed. Furthermore, several agent frontmatters declare `write: false` while `enable_write_tools: true`, causing contradictory tool resolution.
- **Concrete Code Targets in `harness/subagents.py`**:
  1. In `CAPABILITY_BUNDLES` (lines 40–90):
     - Add `send_message` to EVERY capability bundle: `read_only`, `verifier`, `builder`, `orchestrator`, `adversarial_verifier`.
  2. In `_load_builtin_agents()` (lines 95–185):
     - Ensure all 7 specialist personas (`agyis_architect`, `coordinator`, `planner`, `harness_builder`, `harness_custodian`, `harness_auditor`, `harness_reviewer`) include `send_message` in their declared tools.
  3. Reconcile frontmatter permission paradox:
     - When `enable_write_tools: true`, ensure `write: true` is consistent in metadata.
     - When read-only protection is desired (e.g. `harness_auditor`, `planner`), enforce it deterministically via `harness/hooks/anti_drift_hook.py` (`check_auditor_write_block`, `check_plan_mode_lock`), NOT via contradictory frontmatter flags that strip necessary verification tools like `run_command`.

### Directive 2: Align Agent System Prompts with Native Antigravity Primitives
- **Target Files**:
  - `harness/agents/*.md` (in-tree builtins)
  - `~/.gemini/config/plugins/psl-agy-harness/agents/*.md` (installed plugin personas)
- **Modifications Required**:
  1. **Surface Native Slash Commands**:
     - Modern Antigravity natively supports `/teamwork-preview` (Sentinel $\rightarrow$ Orchestrator $\rightarrow$ Explorers/Workers $\rightarrow$ Council $\rightarrow$ Victory Auditor) and `/boost` (`DeepInvestigator` / `DeepCoder`).
     - Remove obsolete warnings discouraging native multi-agent coordination.
     - Update `coordinator.md` and `agyis_architect.md` to recommend `/teamwork-preview` for multi-repository sweeps and `/boost` for deep single-repo refactors.
  2. **Codify the 8 Canonical Empirical Rules**:
     - System prompts must explicitly embed the 8 Ground Rules from `.agents/rules/AGENTS.md` (Automated Verification, Terminal Invariants, Surgical Contiguous Edits, Reactive Wait & Anti-Loop, Artifact-First Planning, Steering Alignment, Cleanroom REA, Dual-Auditor Gate).
  3. **Strict Reactive Wait Invariant**:
     - Explicitly prohibit subagents from running `tail`, `grep`, or `cat` loops on `.system_generated/tasks/*.log`.

### Directive 3: Implement REA GUI Telemetry & DevTools CLI Integration
- **Target Files**:
  - `harness/commands/gui.py` (New command module)
  - `harness/cli.py` (Register `agyis gui`)
  - `harness/hooks/token_proximity_guard.py` (CLI token urgency alert)
- **Concrete Implementations**:
  1. **`agyis gui --devtools` / `--trajectory-debug`**:
     - Reads `/home/kuasha/.config/Antigravity/DevToolsActivePort`.
     - Connects over local CDP WebSocket.
     - Automatically injects `localStorage["jetski.developer.customFlagOverrides"] = JSON.stringify({ "enable-trajectory-debug-tools": true, "enable-developer-mode": true })` and triggers `?trajectoryDebugOpen=true`.
     - Allows instant one-line popping of the native `j5b` token visualizer on the operator's screen.
  2. **`token_proximity_guard.py` (Lifecycle Hook)**:
     - Hook registered in `hooks.json` under `PreToolUse`.
     - Inspects active session SQLite DB in read-only mode (`steps` table).
     - Emits ANSI colored status warnings to stderr when token usage exceeds 35,000 tokens (Amber) and 45,000 tokens (Red Pulse + Terminal Bell `\a`).

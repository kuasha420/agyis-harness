Every tool call checked before and after execution

Prompt instructions drift as context grows. Agyis enforces runtime invariants in deterministic Python hooks registered through seven blocks in hooks.json and verified by eight checks in agyis doctor.

All runtime state isolates cleanly under AGYIS_HARNESS_STATE_DIR, targeting Antigravity Desktop v2.34.0+, agy v1.5.15, IDE v2.8.0, and Gemini 4.

Read the lifecycle hooks contract

  1. PreToolUse / psl-command-safety-guard

    Sanitize shell execution and MCP tool calls

    Injects certified CPython 3.12+ via uv, enforces PAGER=cat and SYSTEMD_PAGER=cat, normalizes eager and lazy MCP tool arguments, guards swarm kill actions during pauses, and shields benign Exit 1 probes.

  2. PreToolUse / psl-anti-loop-guard

    Break repeated reads and status polling loops

    Tracks canonical v2.34 tools including read_file, write_file, edit_file, swarm, and run_workflow, denying three or more identical consecutive calls and blocking background polling loops.

  3. PostToolUse / psl-output-compactor

    Compact verbose passes while keeping errors intact

    Rewrites succeeding run_command outputs above 2 KB and read_file outputs above 32 KB via overwriteResult, leaving every failing command (exitCode != 0 or error payload) 100% verbatim.

  4. PreToolUse, PostToolUse, Stop / psl-stop-verification-fence

    Block done declarations until tests or specs pass

    Tracks decoupled code_dirty and spec_dirty states across tool calls, honors StopHookArgs.continuationActive, and requires agyis test or agyis verify --spec before ending a turn.

  5. PreToolUse / psl-anti-drift-guard

    Keep read-only roles and plan locks enforced

    Guards plan boundaries, native plan-mode locks, auditor write restrictions, and the Q5 read-only shell mutation fence across reviewer, planner, coordinator, auditor, and investigator personas.

  6. PreToolUse / psl-token-proximity-guard

    Monitor scaled 256k, 512k, and 1M context budgets

    Reads active-checkpoint token accumulation in read-only SQLite URI mode (honoring ANTIGRAVITY_APP_DATA_DIR) and scales alerts across Gemini 4 gemini-4-neon and gemini-4-hydrogen windows.

  7. PreInvocation / psl-compaction-advisory

    Pin roles and save checkpoints before compaction

    Tracks the 80-step soft checkpoint horizon, writes CID-scoped checkpoints to .agents/artifacts/checkpoints/ at 70% amber and 90% red thresholds, and emits nested systemMessage advisories.

Onboard any repository in one command

agyis onboard . executes an atomic 10-phase pipeline that isolates branches, invalidates stale caches, prunes duplicate skills, checks database ports, and runs native verification before delivering a pull request.

1. Remote topology probe

Inspects git remotes before touching files to determine whether the repository is a direct collaborator checkout or an external fork, routing push and PR targets safely.

agyis onboard . --dry-run --json

2. Dirty-tree safety patch

Prevents silent loss of local changes on uncommitted repositories by exporting a recovery patch to .agents/artifacts/pre_onboard_safety.patch when --allow-dirty is enabled.

agyis onboard . --allow-dirty --create-branch

3. Feature branch isolation

Checks out an isolated onboarding branch such as chore/agyis-harness-onboarding so baseline commits on main remain untouched during setup.

agyis onboard . --create-branch chore/onboard-harness

4. Build cache invalidation

Purges stale .next/, .turbo/, and node_modules/.cache directories before running verification gates so phantom build artifacts cannot mask regressions.

agyis clean --all

5. Legacy .agent pruning

Migrates legacy .agent/ directories and workflow files into modern .agents/ structure with checksum verification so rules and skills load cleanly.

agyis harmonize . --apply

6. Skill provisioning

Detects the project language runtime and architectural role, or accepts explicit flags such as --lang typescript --role frontend and monorepo --subproject paths.

agyis onboard . --lang typescript --role frontend

7. Database port audit

Inspects host port 5432 collisions on backend and fullstack repositories and rebinds .env cleanly without terminating unrelated host database services.

agyis doctor

8. Skill deduplication

Prunes workspace skills in .agents/skills/ that shadow global plugin skills, recovering roughly 4,500 prompt tokens on every agent turn.

agyis skills --prune-duplicates

9. Native test verification

Executes the target repository native test runner in a clean-room pass and confirms exit code 0 before considering the onboarding branch ready for review.

agyis test

10. Resilient PR delivery

Optionally pushes the isolated onboarding branch and opens a pull request via gh pr create with fork-aware upstream resolution.

agyis onboard . --create-branch --pr

Three-tier customization precedence

Workspaces override machine defaults without duplicating global skills or mutating plugin bundles.

  1. Layer 3: Workspace local (.agents/) Highest precedence. Project-specific rules, bespoke specialists, and local commands.
  2. Layer 2: Workstation user (~/.gemini/config/) Developer preferences, credentials, and personal agents across workspaces.
  3. Layer 1: Global plugin (agyis-harness) Default baseline providing 7 hook blocks, 30 modular skills, and 8 canonical personas.

Install Agyis Harness 1.0.0

Deploy the workstation plugin and agyis CLI in under five minutes, then run agyis doctor to verify your host matrix.

Recommended: clone the v1.0.0 repository and deploy the frozen wheel across all Antigravity surfaces.

git clone https://github.com/kuasha420/agyis-harness.git
cd agyis-harness
./agyis install --global --wheel --all-surfaces
agyis doctor

Install the standalone CLI tool directly via uv without maintaining a local checkout.

uv tool install git+https://github.com/kuasha420/agyis-harness.git
agyis install --copy --all-surfaces
agyis doctor

Enable the opt-in CDP desktop launcher and background ConnectRPC Trajectory Debug HUD service.

agyis gui --install-launcher
# Restart Antigravity from your desktop launcher so Electron binds DevToolsActivePort
agyis gui --service install

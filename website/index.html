  1. PreToolUse / psl-command-safety-guard

    Sanitize shell execution and MCP tool calls

    Injects certified CPython 3.12+ (3.14 recommended) via uv, enforces PAGER=cat and SYSTEMD_PAGER=cat, normalizes eager and lazy MCP tool arguments, promotes inline scripts safely, guards swarm kill actions during pauses, and shields benign Exit 1 probes.

  2. PreToolUse / psl-anti-loop-guard

    Break repeated reads and status polling loops

    Tracks canonical v2.34 tools including read_file, write_file, edit_file, swarm, and run_workflow, allowing 3 identical calls and denying the 4th (MAX_REPEATS = 3) while blocking the 3rd consecutive manage_task status poll.

  3. PostToolUse / psl-output-compactor

    Compact verbose passes while keeping diagnostics intact

    Compacts succeeding run_command outputs above 2 KB and read_file outputs above 32 KB with [... AGYIS Compactor: ...], preserving up to 50 diagnostic lines and scoping exit-code heuristics strictly to _COMMAND_TOOL_NAMES.

  4. PreToolUse, PostToolUse, Stop / psl-stop-verification-fence

    Block done declarations until tests or specs pass

    Tracks decoupled code_dirty (cleared by agyis test) and spec_dirty (cleared by agyis verify --spec) states, returns "decision": "continue" on unverified stops, and applies 2-block anti-deadlock protection.

  5. PreToolUse / psl-anti-drift-guard

    Keep read-only roles and plan locks enforced

    Guards plan boundaries, native plan-mode locks, auditor write restrictions, and the Q5 read-only shell mutation fence across reviewer, planner, coordinator, auditor, and investigator personas.

  6. PreToolUse / psl-token-proximity-guard

    Monitor scaled 512k, 840k, and 1M context budgets

    Reads active-checkpoint token accumulation in read-only SQLite URI mode (honoring ANTIGRAVITY_APP_DATA_DIR) and renders [AGYIS TOKEN GAUGE] on stderr with zero \a BEL alerts across Gemini 4 and Claude Sonnet 5.5 windows.

  7. PreInvocation / psl-compaction-advisory

    Pin roles and save checkpoints before compaction

    Tracks the 80-step soft checkpoint horizon ([AGYIS CHECKPOINT HORIZON ADVISORY]), writes CID-scoped checkpoints to .agents/artifacts/checkpoints/ at 70% amber and 90% red thresholds, and emits nested systemMessage advisories.

Onboard any repository in one command

agyis onboard . executes an atomic 10-phase pipeline supporting --create-branch, --allow-dirty, purge_build_caches(), --verify, --no-verify, --commit, --rea, and --pr while maintaining single-source .agents/ skills.

Phase 1 / 10

1. Remote topology probe

Inspects git remotes before touching files to determine whether the repository is a direct collaborator checkout or an external fork, routing push and PR targets safely.

agyis onboard . --dry-run --json

2. Dirty-tree safety patch

Prevents silent loss of local changes on uncommitted repositories by exporting a recovery patch to .agents/artifacts/pre_onboard_safety.patch when --allow-dirty is enabled.

agyis onboard . --allow-dirty --create-branch

3. Feature branch isolation

Checks out an isolated onboarding branch such as chore/agyis-harness-onboarding so baseline commits on main remain untouched during setup.

agyis onboard . --create-branch chore/onboard-harness

4. Build cache invalidation

Invokes purge_build_caches() to clear stale .next/, .turbo/, and node_modules/.cache directories before verification gates run so phantom artifacts cannot mask regressions.

agyis clean --caches

5. Legacy .agent pruning

Migrates legacy .agent/ directories and workflow files into modern .agents/ structure with checksum verification so rules and skills load cleanly.

agyis harmonize . --apply

6. Skill provisioning

Detects the project language runtime and architectural role, or accepts explicit flags including --lang typescript --role frontend, --rea, and monorepo --subproject paths.

agyis onboard . --lang typescript --role frontend

7. Database port audit

Inspects host port 5432 collisions on backend and fullstack repositories and rebinds .env cleanly without terminating unrelated host database services.

agyis doctor

8. Skill deduplication

Prunes workspace skills in .agents/skills/ that shadow global plugin skills, keeping single-source skill definitions and recovering prompt token headroom on every turn.

agyis skills --prune-duplicates

9. Native test verification

Executes the target repository native test runner in a clean-room pass (controlled by --verify / --no-verify) and confirms exit code 0 before branch delivery.

agyis onboard . --verify --commit

10. Resilient PR delivery

Optionally commits staged onboarding changes (--commit), pushes the isolated branch, and opens a pull request via gh pr create with fork-aware upstream resolution.

agyis onboard . --create-branch --verify --commit --pr

Three-tier customization precedence

Workspaces override machine defaults without duplicating global skills or mutating plugin bundles.

  1. Layer 3: Workspace local (.agents/) Highest precedence. Project-specific rules, bespoke specialists, and local commands.
  2. Layer 2: Workstation user (~/.gemini/config/) Developer preferences, credentials, and personal agents across workspaces.
  3. Layer 1: Global plugin (agyis-harness) Default baseline providing 7 hook blocks, 32 modular skills, and 8 specialist personas.

Install Agyis Harness 1.1.2

Deploy the workstation plugin and agyis CLI in under five minutes, then run agyis doctor to verify your host matrix.

Recommended: build and install the frozen v1.1.2 wheel across all Antigravity surfaces, then enable the optional Trajectory HUD launcher.

git clone https://github.com/kuasha420/agyis-harness.git
cd agyis-harness
./agyis install --global --wheel --all-surfaces
agyis doctor

Run directly from a source checkout and onboard any target workspace on an isolated branch.

git clone https://github.com/kuasha420/agyis-harness.git
cd agyis-harness
./agyis test
./agyis onboard /path/to/repo --create-branch --verify

Install in editable mode inside a Python 3.12+ (3.14 recommended) virtual environment for contributor development and local hook testing.

python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/agyis doctor
.venv/bin/agyis audit aff

Install the standalone agyis CLI via uv without maintaining a local checkout, plus optional ConnectRPC Trajectory HUD setup.

uv tool install git+https://github.com/kuasha420/agyis-harness.git
agyis install --copy --all-surfaces
agyis gui --install-launcher
agyis doctor

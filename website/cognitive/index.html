Cockpit Flight Director and 12-workflow router (A to L)

Defined verbatim in harness/subagents/routing.py (Protocol 2026.1). Invoke via agyis cockpit route <letter|alias>, agyis router <alias>, or agyis ladder <alias>.

Four multi-agent execution modes

  • LADDER: Sequential specialist quality gates (Investigator, Planner, Builder, Reviewer, Custodian, Auditor).
  • PARALLEL_FANOUT: Coordinator-led parallel research and diagnostic tracks without context cross-contamination.
  • TEAMWORK_DAG: Native /swarm, run_workflow, or /teamwork task graphs with isolated worktrees.
  • BOOST_TOURNAMENT: Native /boost multi-perspective competition pairing Deep Coding Agents with High-Reliability Reviewers.

Gate 2 dual-auditor certification

Code authors never self-certify production diffs (PSL-INV-006). Before branch promotion, independent Reviewer and Auditor specialists evaluate the clean committed revision on HEAD.

  • agyis_reviewer (Hammer): Delta-focused diff review (git diff -U3) checking DRY duplication and architectural smells.
  • agyis_custodian (Commit Gate): Enforces 4-pillar AFF hygiene and atomic commits without repo document pollution.
  • agyis_auditor (Victory Auditor): Executes the full hermetic test suite, agyis audit aff (100.0/100), and agyis doctor, writing signed .agents/artifacts/audit_verdict.json.

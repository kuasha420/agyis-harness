Telemetry source and voluntary provenance ledger

Every figure on this observatory traces back to two transparent contribution streams, redacted client-side before leaving developer workstations and verified against automated leak gates before publication.

Zero third-party SaaS analytics and zero background phone-home

Synchronization is strictly opt-in through agyis sync or the optional user daemon (agyis sync --service). PSL operates an internal hub compiled directly from the open-source server/ directory in this repository. All prompt bodies, emails, secrets, and local home paths are removed client-side before upload and re-checked during static bundle export.

Self-hosted open-source sync architecture

Built with Starlette ASGI (server/app.py), GitHub PAT and purrfectsoft organization verification cached for 300 seconds (server/auth.py), and dual PostgreSQL/SQLite storage (server/storage.py). Corpus hygiene also repaired 256,841 duplicate telemetry rows via harness/telemetry/integrity_dedup.py.

Model and reasoning-tier reliability matrix

Compares attributed reasoning tiers across tool error rate, per-call reliability, step horizon, and deliberation depth. Unattributed legacy buckets remain isolated off by default.

Metric honesty note on accuracy_percent: In models.json, accuracy_percent measures strict zero-error sessions (0 tool errors across an entire run), not task pass rate. Deep frontier runs such as gemini-4-neon (7 sessions, 399.4 average steps, 76,604 average thinking tokens) execute hundreds of shell probes and record 0.0% zero-error runs while sustaining a 4.12% tool error rate (95.88% per-call reliability).
